# 🎨 Global UI Design Philosophy

## Layout Style
- Modular grid dashboard
- Glassmorphism + subtle neumorphism blend
- Premium dark + adaptive light theme
- Smooth animated gradients
- Floating card UI
- Minimal clutter
- High data visibility

---

## Interaction Design Rules
- Hover = Glow elevation + micro scale
- Click = Smooth ripple or energy burst
- Progress bars = Animated growth
- Loading states = Skeleton shimmer loaders
- Transitions = Framer Motion style physics animations

---

## Color Palette
- Primary: Deep Tech Blue / Neon Indigo
- Accent: AI Purple Glow
- Success: Neon Green
- Warning: Soft Orange
- Background: Ultra Dark Gradient / Clean White Mode
