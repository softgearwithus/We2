# Tier 2 / Tier 3 College UX Strategy

---

# 🎯 Design Principles

• Simple Navigation
• Minimal Technical Complexity
• Clear Data Visualization
• Language Neutral Interface

---

# 🧑 Target Users

- HODs
- Placement Officers
- Directors
- Non-Technical Faculty

---

# ⭐ Experience Priorities

- Large readable UI
- Minimal Dropdown Complexity
- Guided Dashboard Tooltips
- One Click Report Export

---

# 📊 Cultural Usability Adaptation

- Academic Terminology
- Familiar Institutional Metrics
- Clear Progress Indicators
